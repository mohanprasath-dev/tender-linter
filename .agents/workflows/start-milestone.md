---
description: Start a milestone M0 to M16 safely
---
1. Ask which milestone. Open `docs/prompts/build-prompts.md` and `docs/PROJECT_SPEC.md` for it.
2. List dependencies from spec 16.6 and confirm they are done.
3. List any missing facts and ask the user before coding.
4. Create a branch `feat/mN-short-name`.
5. Write tests first, then implement.
6. Run lint and tests. Open a pull request with the template.
7. Report: built, tested, unverified, "done when" status.
