# Deck claim check

**Goal:** No slide claims more than was built, measured or verified.

## Instructions
1. Take the slide text. For each claim output a table: slide, claim, maps to (file, feature, or verified row), or UNMAPPED.
2. List UNMAPPED claims for removal. Do not soften them into vaguer claims.
3. Check: exactly six slides, PDF upload, Team ID and theme match the portal, exact model name and bake-off date on the technical slide, one measured number as "X of Y on test set Z", no em dashes, no placeholder text.
4. Check that each shown source link opens and a verified date is displayed.

## Constraints
- Do NOT use UNVERIFIED facts (CCTV, migration date, cement QCO, IS 302-1, IS 875, IS 1893).
- Do NOT describe planned features as built.
- Do NOT apply synthetic results to real tenders.
