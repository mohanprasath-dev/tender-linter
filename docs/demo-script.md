# Demo Script (about 4 minutes, synthetic clauses only)

Pre-flight: demo environment, fixed rule set version, cache pre-warmed for these clauses, regex-only mode tested as safety net. Banner visible.

1. **Open** (20 s). State the problem in one sentence. Show the banner: flags, does not approve.
2. **T01** (60 s). Paste the laptop clause citing IS 13252 (Part 1): 2010. Show R05 and R06, click the evidence link, show the verified date.
3. **T13** (20 s). Clean clause, no findings. Shows low false alarms.
4. **T07** (30 s). Product not in dataset. Show "No applicable standard in our dataset". Say why abstaining is a feature.
5. **T12** (60 s). Hindi clause. Highlight sits on the original Hindi text; message in Hindi.
6. **Extraction editor** (30 s). Fix an extraction, rules re-run instantly.
7. **Export** (20 s). Open the PDF report; point to version footer.
8. **Measured result** (20 s). Read the "X of Y on test set Z" line from the evaluation harness.

Do not demo: anything marked UNVERIFIED, cement, CCTV, real tender text, any language not passing the quality gate.
Fallback: recorded video, and regex-only mode with the "reduced mode" label.
